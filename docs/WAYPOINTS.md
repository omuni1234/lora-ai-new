# 有限の共通地点集合を使うWaypoint移動（v0.9）

`kind: waypoints`、`options.mode: random_waypoint` を選びます。GUIでは「EDグループ → 移動モデル」または「モデルライブラリ → 移動モデル」で設定できます。新規モデルの既定方式です。

```yaml
mobility:
  kind: waypoints
  options:
    mode: random_waypoint
    waypoint_count: 100
    waypoint_seed: 0
    waypoint_height_m: 1.5
    speed_min_m_s: 0.5
    speed_max_m_s: 2.0
    pause_min_s: 5
    pause_max_s: 30
```

## 遷移規則

1. エリア `[0, width) × [0, depth)` に `waypoint_count` 個の地点を一様生成します。高さは `waypoint_height_m` です。同じ実験内の同一設定は、グループをまたいでも同じ読み取り専用の地点配列を共有します。
2. 各EDはこの集合から初期地点を独立に一様選択します。グループのuniform/grid/explicit配置は、この方式では初期位置として使用しません。初期地点での待機はなく、時刻0から最初の移動を開始します。
3. 現在地点を除く残りの地点から、次の目的地を等確率で選びます。1地点の場合は永続的に静止します。到着先を選ぶ際、他EDの選択・位置は参照しません。
4. 出発ごとに速度を `Uniform(speed_min_m_s, speed_max_m_s)` から抽選し、その区間では一定とします。2点間を直線移動します。到着時刻は出発時刻＋距離／速度です。
5. 到着時に静止時間を `Uniform(pause_min_s, pause_max_s)` から抽選します。同じ地点でも再訪ごとに新たに抽選します。静止終了時刻に次の目的地・速度を選びます。

速度の最小値は正、静止時間の最小値は0以上、最大値は最小値以上です。同じ上下限なら固定値です。NumPyの一様乱数の上端は原則として含みません（浮動小数点丸めを除く）。

## 乱数と再現性

- 地点生成：`SeedSequence([profile.seed, waypoint_seed, 920])`。地点数・エリア・高さ・地点seedが同じモデルで配列を共有します。
- 初期地点、移動先、速度、静止時間：既存のED専用 `SeedSequence([profile.seed, device_id, 2])`。共有モデル定義を使ってもRNGと現在の区間状態は共有しません。
- `waypoint_seed` は配置のみを制御します。旧 `random_seed` は `route` 用で、新方式では使用しません。全EDの軌跡を同じ乱数列に揃えることはありません。
- 位置照会の密度は軌跡に影響しません。細かい照会と途中を飛ばした照会で、同じ時刻の位置・乱数状態が一致します。照会は時刻の非減少順で行います。
- 長さが伸び続ける全経路を保存せず、地点集合と現在の移動／静止区間のみを保持します。状態量は地点集合あたりO(W)、EDあたりO(1)です。

## GUIで確認する

中央上部の「設定を確認する」で、EDの初期配置・軌跡サンプル・生成予定を確認できます。「ウェイポイント」チェックで共通地点を表示／非表示にできます。地点表示は最大1000点、EDは指定したサンプル上限までです。軌跡は時刻サンプル間を結んだ表示なので、途中の全ての訪問点を描画するわけではありません。

プレビュー全体の新方式の出発処理は最大10000回に制限します。極端な速度・長い時間範囲などで上限に達した場合はEDの詳細に日本語で省略理由を表示し、以降の位置は初期地点を表示します。本実験の状態・乱数には影響しません。シミュレーション中の表示処理・通信は追加していません。

## 旧方式

- `mode: timed`：`points: [[time_s,x,y,z], ...]` に沿って補間します。`mode` なしで `points` を指定した旧プロファイルも時刻指定として読み込みます。
- `mode: route`：指定座標またはED別に生成した地点を順番に訪問する従来のモデルです。`repeat` と地点別の静止時間割当を保持します。
- `options: {}` のWaypointはv0.9から新方式です。旧既定の時刻経路を維持したい場合は `mode: timed` を明示してください。既存Runの保存プロファイルと結果は変更しません。

実行例は `examples/10-random-waypoints.yaml` と `examples/16-d-lora-waypoints.yaml` です。
