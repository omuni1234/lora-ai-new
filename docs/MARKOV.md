# マルコフ拠点移動

`plugins/mobility/markov.py` は点を状態とするマルコフ連鎖に、連続座標の拠点間移動を組み合わせたモデルです。実装は特定の実測移動分布を再現したものではなく、研究者が遷移行列を設定するためのモデルです。

1. `points` で拠点を指定するか、`random_count` と `random_seed` でエリア内に一様生成します。
2. 初期位置から `initial_point`（未指定なら最近傍）へ指定速度で移動します。初期位置を瞬間移動させません。
3. 拠点iへ到着すると、到着基準の `decision_interval_s` ごとに遷移行列Pで次状態を抽選します。
4. i→iはその拠点での滞在継続。i→jではjまで直線移動し、到着後に同じ処理を繰り返します。移動中に目的地は変えません。

`Pii < 1` では出発までの判定回数Gは幾何分布で、`P(G=k)=Pii^(k−1)(1−Pii)`、平均滞在時間は `decision_interval_s/(1−Pii)`。`Pii=1` は吸収状態で永続滞在です。実装は自己遷移を1回ずつ計算せず、幾何分布からまとめて抽選し、退出先を `Pij/(1−Pii)` で選びます。この圧縮で分布を変えずに長い滞在を処理できます。これは連続時間マルコフ連鎖の指数滞在モデルではありません。移動時間を含む全過程は点状態だけの離散時間連鎖とは区別します。

行列を空にすると、`stay_probability` を対角要素、残りを他拠点へ等分した行列になります。1拠点なら吸収状態。明示行列は拠点数×拠点数、非負、各行合計1（許容誤差1e−12）を検証します。許容誤差内の合計は乱数器へ渡す前に正規化します。

速度は `speed_m_s`、各区間の揺らぎは一様分布±`speed_jitter_m_s`。揺らぎは基準速度より小さく指定します。拠点はすべてエリア内、Z座標も設定可能です。乱数シード未指定ならED別乱数であり、同じシードを明示したモデルは同じ拠点集合・乱数列を使います。

プレビュー・実行とも同じモデルを使用します。問い合わせ時刻は単調非減少で、細かく多数回問い合わせても、まとめて将来へ進めても同じ位置になります。過去の軌跡は保持せず、拠点・行列と現在区間のみを保持します。1回の問い合わせで10万回を超える退出が必要なら計算予算超過としてエラーにします。短すぎる判定間隔と極端に長い期間の組み合わせを避けてください。

サンプル: `examples/13-markov.yaml`。左側のモデル定数で全項目を編集できます。
