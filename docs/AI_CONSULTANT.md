# AIコンサルタント（v0.10.1）

Calculator内の「AIコンサルタント」から、現在のプロファイル、または保存済みRunのプロファイルとアブストラクトについて相談できます。必要なら近似予測も添付できます。保存済みRunを選んだ場合は、編集中の別条件ではなく、そのRunのスナップショットを使います。

## 接続設定

OpenAIの [Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) を使います。既定の接続先は `https://api.openai.com/v1` です。URLを省略・空欄にしてもこの接続先になります。モデル名は利用するAPIプロジェクトで利用可能なものを明示します。

Docker Composeを使う場合、サーバーの `.env` に次を設定します。APIキーは [OpenAI公式の認証仕様](https://developers.openai.com/api/reference/overview#authentication) に従い、サーバー環境変数から読み取り、Bearer認証に使います。アプリ自身の任意認証 `LORASIM_API_TOKEN` とは別です。

```dotenv
# OpenAIの場合。モデルはアカウントで利用できる名前を指定する。
LORASIM_AI_BASE_URL=https://api.openai.com/v1
LORASIM_AI_MODEL=利用するモデル名
LORASIM_AI_API_KEY=自分のAPIキー
LORASIM_AI_MAX_TOKENS=2000
```

上のモデル名・APIキーは説明用の値なので置き換えてください。ソースを更新したら、次のコマンドでAPIコンテナへ反映します。

```sh
docker compose up -d --build --no-deps api
```

`.env`だけの変更なら `--build` は省略できます。単なる `docker compose restart api` では環境変数の変更が反映されません。APIのみの更新なので、実行中のworkerを再起動しません。Dockerを使わない場合、このアプリは `.env` を自動読込しないため、同名の環境変数をAPI起動プロセスへ渡してから再起動します。

ローカルサーバーの場合は `LORASIM_AI_BASE_URL=http://接続先ホスト:ポート/v1` と、そのサーバーのモデル名へ変更します。APIキー不要なら空欄にします。Ollama等については利用する版・モデルが `messages` と `max_completion_tokens` を含むChat Completions形式に対応するか確認してください。Docker内の `localhost` はAPIコンテナ自身なので、Ubuntuホスト上の推論サーバーにはコンテナから到達可能なアドレスを使います。

OpenAIのモデル名・APIキーが未設定、URLが不正、または出力上限が正の整数でない場合は、不足・不正の内容と設定方法を日本語で表示し、送信ボタンを無効にします。APIキーはブラウザーやプロファイルへ返しません。環境変数からAPIプロセスだけが読み取ります。画面の接続設定表示は入力の確認であり、モデルへのアクセス権・キーの有効性を検証した結果ではありません。実際の接続は送信ボタンを押した時だけ行います。

HTTP 401は認証、403はアクセス権、404はURL・モデル・利用権限、429はレート制限・利用枠の確認へ案内します。応答の生データをエラー表示へ転記しません。`max_completion_tokens` は推論トークンも含む上限です。上限に達した場合は画面に表示する案内に従い調整してください。

## 相談の流れ

1. 相談対象を選ぶ。Runが新しく追加された場合は「相談対象のRun一覧を更新」。
2. 必要なら「近似予測を添付する」を選ぶ。
3. 「送信データを確認する」で、ローカルに構成したJSONを表示する。この段階ではAIへ接続しない。
4. 質問と、画面に表示された接続先URL・モデル名を確認する。
5. 「確認したデータと質問をAIへ送信」を押す。この操作で初めて選択したAIへ送信する。

結果は日本語テキストとして表示します。接続失敗・タイムアウト・APIの拒否には日本語の理由と対処を表示します。設定や対象が変わると、古い送信データ・回答を破棄して再確認を要求します。

## データと動作の範囲

送信対象は表示されたJSONと質問、およびシミュレーターの境界を説明する固定のsystem指示です。生パケットParquetを走査したり、ソースコード・環境変数を収集したりしません。通知設定・モデルファイル参照・既知の秘密キー名（token、password、api_key等）は再帰的に除外します。独自オプションに埋め込んだ任意の秘密情報を完全に検出する機能ではないため、表示内容を確認してください。

相談は読み取り専用です。AIにプロファイルの自動変更、コード実行、シミュレーション起動用のツールを渡しません。回答はHTMLとして実行せず、文字列として描画します。AIの指示文では実測と近似を分け、判断の根拠・比較条件・短い確認実験を求めていますが、回答の正確性は保証しません。

相談履歴はサーバーに保存しません。1回の質問に選んだデータを添付する方式で、過去の回答を自動的に次の質問へ送信しません。AI提供元による保管・料金は、その接続先の設定と契約に従います。

JSON上限180 KB、質問6000文字、応答2 MB、接続待ち60秒、APIプロセスあたり同時1相談。リダイレクト先にAPIキーを引き継ぎません。

API：`GET /api/consultant/config`、`POST /api/consultant/preview`、`POST /api/consultant/ask`。実装は `lorasim/consultant.py`。接続仕様は公式ドキュメントで確認し、外部有料サービスへの実送信は今回行っていません。模擬サービスで要求形式・応答・エラー処理を検証しています。
