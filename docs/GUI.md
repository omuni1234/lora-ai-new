# GUI操作ガイド（v0.12）

## 実験ワークスペース

左のメニューで項目を選び、中央下部で設定します。中央上部は実験前の確認、右は実行進捗・Run一覧・結果です。設定変更は自動保存ではありません。「プロファイルの保存・読み込み / Experiment」を開いて保存してください。

「基本設定」の名前入力の右にある「名称を反映」で、`ED数-選択器-移動モデル-mmddHHMM-一意ID`へ入力値を変更します。日時は日本時間。モデル参照と条件付き割り当てを考慮し、複数実装が混ざる場合は`mixed-種類数`になります。8桁のランダムIDを付けます。長い独自実装名は各36文字までに短縮します。保存・実行は別の操作です。

### 同梱YAMLの複数選択・一括実行

「プロファイルの保存・読み込み / Experiment」内に、`examples`以下のExperiment YAMLをチェックボックス付きで一覧表示します。ファイル名・実験名で絞り込み、「表示中を全選択」または個別チェックで選びます。絞り込みを変えても選択は維持され、表示外の選択件数も表示します。「選択をすべて解除」は表示外も含めて解除します。

「選択したYAMLを一括実行」で、各YAMLを通常の検証・実行キューへ1件ずつ登録します。各YAMLにつき独立したExperimentと1 Runを作り、seedを含む設定はそのファイルの値を使います。エディタの変更や選択中のExperimentは一括実行へ適用しません。登録件数とYAML別の結果・Runへのリンクを表示します。登録完了まで画面を開いておいてください。登録済みRunは既存workerが順次実行し、画面を閉じても継続します。

登録中は選択と一括実行をロックし、成功した項目を選択から外します。設定エラーの項目は理由を表示して選択を残し、残りを続行します。登録要求の通信切断等で結果が不明な場合はそこで止め、不明な項目を自動再送しません。Run一覧で登録状況を確認してから再選択してください。まだ要求していない項目は選択されたままです。

1件だけ選ぶと「1件をエディタへ読み込む」が使えます。参照モデルを展開して取り込み、編集・検証後に上部の「エディタの設定を実行」で実行できます。モデル定義だけのYAMLは候補に入りません。[TVTの設定・評価手順](TVT_GUI_EXPERIMENTS.md)も参照してください。

### 配置・移動の確認

初期配置、移動の例、生成予定を確認します。実行中のライブ表示ではなく、独立した標本による事前確認です。配置の縦横は同じ距離縮尺です。

### Calculator

[伝搬距離](CALCULATOR.md)、[トレードオフ予測](TRADEOFF_FORECAST.md)、[経験分布](EXPERIENCE_DISTRIBUTION.md)、[AIコンサルタント](AI_CONSULTANT.md)を利用できます。経験分布の生成予定と、実験後の実送信の統計は別です。

### Abstruct · 設定一覧

概要表、設定分野ごとの数値表、モデル参照を展開した定数表を表示します。モデルの既定値も最後の表で確認できます。設定変更後は「最新の入力値で更新」を押してください。YAML欄の未適用編集は表示されません。空欄/nullは継承・既定値など文脈に依存します。ここでの表示は設定検証の代わりではありません。

## 比較・分析

1. 上部「比較・分析」を開き、左でExperimentを選択します。
2. 送信通番の区間、ED数、MCUの有無を設定します。
3. 中央下部の選択欄から必要なモジュールを「＋追加」します。チェックがオンのものだけ計算します。
4. モジュール固有の条件（地図分割、SF、距離境界、ED IDなど）を設定します。
5. 「選択した実験を分析」を押します。設定変更後は再集計してください。

既定は数値一覧・損失・累積収束・PRR対ED数・公平性・エネルギーです。モジュール一覧は内蔵実装から自動生成され、TVTの7モジュールも追加できます。[既存指標](RESEARCH_ANALYSIS.md)と[TVT評価の定義](TVT_GUI_EXPERIMENTS.md)を確認して比較してください。

- グラフにホバー／キーボードでフォーカスすると値が表示されます。折れ線は標本数も表示します。
- 「数値ラベルを表示」で少数点の図は各点、多数点の図は終点の値を表示できます。
- PRR折れ線の縦線は複数Runの最小〜最大。信頼区間ではありません。
- 表は100行ずつ表示し、表ごとのCSV保存ができます。値は表示桁数を整え、ホバーでは元の数値を確認できます。CSV/JSONは丸める前の値です。
- 中央上下の境界はリサイズできます。スクロールして他の図を確認してください。
- JSONは全モジュールのデータを含みます。左側のCSVは基本Run統計、各表のCSVはその表の全行です。

旧結果にはSEMA時系列や送信時の移動状態がない場合があります。取得できない値を推測してグラフへ補わず、理由を表示します。

## モデルライブラリ

内蔵の実装または独自のPython実装から、定数の組を保存できます。各EDのエージェント状態は独立です。ライブラリの定義を共用することは学習状態の共用ではありません。

## ドキュメント

左の検索欄はタイトルと本文を検索します。文書を選択し、目次から節へ移動します。文書内の他のMarkdownへのリンクも同じ画面で開きます。「Markdown原文」でコードを含む元テキスト、「Markdownを保存」で元のmdを取得できます。同梱画像はAPIの認証条件に従って読み込みます。任意のHTMLは実行しません。

文書は実行中のサーバーと同梱されたものです。ソース変更後のDocker配布ではAPIとworkerを再ビルドしてください。過去の検証文書には履歴表示が出ます。実験の設定・Runを変更する操作はこのタブにはありません。

## モデルのハイパーパラメータ調整（v0.13）

モデルカードの「このモデルを調整」から、項目候補・探索方法・評価時間・seedを指定します。短い評価から絞り込み、別seedで確認した候補を新しいモデル定義として保存できます。実験条件は取り込み時点で固定されます。手順と評価上の注意は [TUNING.md](TUNING.md) を参照してください。

## v0.14：分析結果のAI考察

中央上部で「分析グラフ」と「AIコンサルタント」を切り替えます。分析後に相談データを準備し、質問を送信すると逐次回答されます。続けて質問・停止・会話JSON保存が可能です。右上または相談画面の「OpenAI接続設定」で接続先・API形式・APIキー・モデル等を保存できます。[詳細](AI_CONSULTANT.md)。

## ED数と選択器をまとめて比較する（v0.14.1）

ワークスペース上部の「ED数 × アルゴリズム · 一括実行」で、ED数リストとモデルリストを登録します。100・200・300台 × Bandit・DQNでは6 Run。確認表で配分・保存先・Warningを確認してからキューへ追加します。各選択器は現在のグループ設定、保存済みライブラリ、内蔵モデルから選択できます。標準では選択器ごとにExperimentを作成し、既存の比較・分析で利用できます。[詳細](BATCH_RUNS.md)。
