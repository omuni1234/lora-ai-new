# SF×CH比較、SEMA、DQN

## 実験共通の行動空間

プロファイルの `action_space` をGUIの「比較用の共通SF×CH行動空間」から設定します。

```yaml
action_space:
  spreading_factors: [7, 8, 9, 10, 11, 12]
  frequencies_hz: [868100000, 868300000, 868500000]
  tp_dbm: 14
  cr: 1
```

CHはサブバンドIDではなく、サブバンド内に登録した離散的な中心周波数です。候補は `sub_bands[].channels_hz` に登録し、そのバンドを `ul_sub_bands` で許可します。CH候補の重複、範囲外、未登録値、TP超過を検証します。GWの受信チャネル設定は独立です。意図的な `WrongFrequency` 実験を可能にするため、GWが全CHを受信することまでは強制しません。

行動IDはSFのリスト順を外側、CHのリスト順を内側に並べます。上記なら0=(7,868.1MHz)、1=(7,868.3MHz)、…、17=(12,868.5MHz)。TPとCRは固定です。対応モデルが共通空間の外の行動を返すと実行を停止します。プロファイルが実行時に固定保存されるため、事後に同じ対応表を復元できます。

| kind | 腕・更新 | 原手法との差 |
|---|---|---|
| `linucb_sf_ch` | SF×CHごとに独立した6次元LinUCB統計 | SF腕と独立CHホッピングを、共同選択する腕へ拡張。SNRゲート・報酬・DL通知は原実装を維持 |
| `lora_mab_sf_ch` | 共通SF×CHのExp3、ACK 0/1報酬 | 元のSF×CH×TPからTPを共通値に固定 |
| `fixed_sf_ch` | 共通集合内の1つのSF/CHを固定使用 | TP・CRは共通値 |
| `bandit_sf_ch` | 従来のACK/エネルギー代理報酬、標本平均更新 | 共通SF×CHへ候補を統一。SEMA内部のε-greedyとは別 |
| `random_sf_ch` | SF×CHから一様抽選 | 比較用の非学習ベースライン |
| `dqn` | ACK RSSIの1次元状態、SF×CH | SEMAと同じ下位DQNを単独使用 |
| `sema` | 6つのアルゴリズム組から選び、下位がSF×CHを決定 | 添付修士論文に対応 |

原版 `linucb_sf` / `linucb_sf_tp` / `lora_mab` とADR/GADR/BADR等は従来の設定を維持し、共通空間を強制しません。ADRにはCHの学習則がないため、SF×CH学習モデルの名義を付けていません。共通空間の比較には上表のモデルを選択してください。

**行動空間の統一と報酬の統一は別です。** `lora_mab_sf_ch` は元LoRa-MAB論文のExp3・ACK報酬を維持します。修士論文5.1.3のLoRa-MAB比較には異なるγ式・報酬・重み加算が記載されており、その結果をこのモデルで再現したとは主張しません。LinUCBは9 byteのGW測定通知をDLに加える既存仕様を維持し、DQN/SEMAには追加通知がありません。実験間比較ではこの通信量差も含まれます。

## 添付PDFとの対応

参照: `修士論文_final (6).pdf`（60ページ、本文ページ番号とPDFページ番号は4ずれる）。SHA-256:
`60e0fefc8c2b43be23366441e2fa6cdfff328e7647a54e89024e982a041c72f2`。
本文19–25、31–32ページ、Algorithm 1、式4.2–4.14、5.5–5.6、表5.4–5.5を直接確認しました。PDF自体は配布物に含めません。

- DQNの入力は1要素、EDが受信したACKのRSSI。GW側のUL RSSI/SNRや他EDの状況は渡しません。
- ネットワークは1→64→64→K、隠れ層ReLU、出力線形。MSEで `r + γ max Q_target(o′, a′)` を学習します。Double DQNやDueling DQNへの置換はしていません。
- 報酬はACK成功時 `(13−SF)/6`、不達時−1（式4.3）。メタ報酬はACKの0/1。
- 既定値はbuffer=10,000、batch=128、γ=0.5、学習率0.01、探索率1→0.01、減衰定数1,000、ターゲット更新16、Adam（表5.5）。GUIで変更できます。
- SEMAの静止プールはA/B/ε-greedy、移動プールはA/C。Aは同一インスタンスを両状態で共有し、B/Cは独立です。
- メタ腕は `(静止候補, 移動候補)` の6組。生存腕から毎回一様選択。式4.11の半径 `δconf sqrt(2 ln T / n)` を用い、最大LCBよりUCBが低い腕を消去します。
- 選択時の2D座標差が距離閾値を超えれば移動。移動→静止時にはε-greedyの累積報酬と探索カウンタをリセット。メタやDQNはリセットしません。
- ACK結果を、選択された手法だけでなく現在の状態プールの全DQNへ渡します（式4.7）。各DQNは独立の重み・Adam状態・再生バッファを持ちます。
- ε-greedyは式5.5の**累積報酬**最大の行動を利用し、式5.6 `max(0.1,20/(20+t))` で探索します。標本平均へ読み替えていません。

Adamは [Kingma & Ba, Algorithm 1](https://arxiv.org/pdf/1412.6980) のバイアス補正を実装しています。追加のTorch依存なしでNumPyを使用します。DQNの数値計算はfloat64です。

## 論文で未指定の事項と実装上の選択

論文の実験曲線との完全一致は未検証です。以下は原文の仕様と区別した実装選択であり、調整可能な項目はGUIに説明付きで公開しています。

1. ACK未観測時RSSIは−120 dBm、不達時は最後の受信値を保持。初期値を変更可能。成功ACK以外の仮想RSSIを生成しません。
2. 次状態は当該試行のACK処理が完了した時点の保持RSSI。再送も1つの学習ステップです。実験時間切れで未確定の試行は学習しません。
3. DQN探索率は `end+(start−end)exp(−n/decay)`。nはその学習器に入った経験数で、SEMAの共有経験を含みます。
4. bufferがbatch件に達するまで学習待機。重複なし一様抽出、毎経験1回更新、16**勾配更新**ごとの完全コピー。`train_every` を増やせますが、物理計算の等価な高速化ではなく学習条件の変更です。
5. 各層の重み・バイアスを `U(−1/√fan_in,1/√fan_in)` で初期化。Adam β1=.9、β2=.999、ε=1e−8。最大値の同点は先頭行動、経験再生は独立ED乱数を使用。SEMAのε-greedyのtは、その手法を選択してACK成否が確定した回数とします。
6. 未試行メタ腕の信頼区間は無限幅として消去しません。全試行数Tには消去済み腕も含みます。消去判定はそのステップの同じ信頼区間で一括判定します。
7. 移動閾値1 m、信頼係数δconf=1は未指定の実装既定値。初期位置を時刻0で観測し、最初の送信までに移動した場合も判定します。
8. RSSIのoffset=0/scale=1が既定。任意の正規化を設定できます。共有学習は同期的に完了させてから次のイベントへ進みます。

SEMAのグループには `observe_position: true` が必要です。DQNは位置情報を使用しません。両者とも `confirmed: true` が必要です。

## メモリ・記録・利用方法

再生バッファは最大件数付きの配列で、使用量に応じて増やします。容量10,000の場合、1学習器の経験配列は約320KB（4列float64）。SEMAはEDごとに3学習器、加えてネットワーク・Target・Adam状態を保持するため、ED数と隠れ層サイズに比例してRAMが増えます。全経験履歴をリストへ蓄積しません。

`policy_state.jsonl` にED別の経験件数・勾配更新回数・最終loss・ACK RSSIを保存。SEMAは6腕の試行数、報酬、生存腕、消去時点、下位選択回数、リセット回数も保存します。ネットワーク重みや再生バッファの再開用チェックポイントではありません。送信ごとのSF/CH/ACK/RSSIは従来のParquetで追跡できます。

```bash
lorasim run examples/12-sf-ch-comparison.yaml --output runs/sf-ch-demo
lorasim run examples/13-markov.yaml --output runs/markov-demo
```

例12は同じネットワーク内に4群を置く機能確認用で、小さなネットワーク・batchを指定しています。性能比較ではモデルごとに独立したExperimentを作成し、同一配置・移動・トラフィック設定と複数seedで実行してください。モデルの選択によってMAC待機時間が変わるため、実際の送信時刻や観測位置は一致するとは限りません。

プレビューではDQN系モデルの推定メモリ総量が64 MiBを超える場合、選択例の生成を省略し警告を表示します。配置・経路の確認は継続できます。
