利用できる比較アルゴリズム

ADR — 上流AdrComponentのネットワーク側決定を、模擬LinkADRReqでEDへ伝達します。標準ADR backoffにも対応します。

BADR — SemtechのBlind ADR方式。SFの列を繰り返します。順序・比率は実験条件です。

Fixed / Random / Bandit — 固定設定、ランダム選択、ACKによる学習。
